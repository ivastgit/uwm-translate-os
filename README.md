# UWM TRANSLATE — Research Translation Operating System prototype

Static GitHub Pages prototype inspired by the interaction model of PolicyEngine and the visual language of the earlier UWM TRANSLATE prototype.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `uwm-translate-os`).
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. GitHub will provide the public Pages URL.

## Files
- `index.html` — homepage
- `styles.css` — all styling
- `domain.html` — reusable domain detail prototype
- `library.html` — artifact library prototype
- `contribute.html` — contribution intake concept

All metrics/statuses shown are prototype placeholders and should be replaced with approved UWM TRANSLATE data.

# UWM TRANSLATE — Research Translation Operating System prototype

A static GitHub Pages prototype designed to visually match the clean UWM TRANSLATE prototype while applying the Research Translation Operating System / PolicyEngine-inspired concept.

## Files
- `index.html` — homepage
- `domain.html` — reusable domain page; query parameters: `faculty`, `industry`, `funding`, `ip`, `capacity`, `skills`
- `library.html` — curated Tools & Practices library
- `contribute.html` — plain-language contribution pathway
- `styles.css` — all shared visual styles

## Publish with GitHub Pages
Upload **all five files plus this README to the root of the repository**. In GitHub go to **Settings → Pages → Deploy from a branch → main → /(root)**.

No build process, framework, external fonts, images, or JavaScript libraries are required. The only JavaScript is a small inline script on `domain.html` that changes the domain content based on the URL query parameter.
